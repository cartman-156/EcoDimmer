# Contributing to EcoDimmer

We welcome contributions! 

### Project Nature
Please note that this project was primarily developed using **Antigravity** (an AI coding assistant). While human contributions are encouraged, we recommend keeping changes modular and well-documented to maintain the clean architecture established by the AI.

### How to contribute
1. Fork the repository.
2. Create your feature branch (`git checkout -b feature/AmazingFeature`).
3. Commit your changes (`git commit -m 'Add some AmazingFeature'`).
4. Push to the branch (`git push origin feature/AmazingFeature`).
5. Open a Pull Request.

### Build Requirements
- Android SDK (API 34)
- Gradle 8.6+
- Kotlin 2.0.0+
